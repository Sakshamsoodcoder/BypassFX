Terms and Privacy Policy

This is a demo application. By creating an account, you agree to the following terms for the purpose of this demonstration.

1. Account and Data

Your user information (name, email, and password) will be stored in a `db.json` file. As noted in the project's README, passwords are stored in plain text. This is not secure and is for demonstration purposes only. Do not use a real-world password.

2. Data Usage

The data you provide and the conversions you perform will be saved and visible within the application's context. This data is stored locally in `db.json` and is not transmitted to any external server other than the local `json-server` instance.

3. No Real Financial Transactions

Bypass-FX is a simulator. No real money is ever transferred or converted. The currency rates are fetched from a live API for realism, but all calculations and "transactions" are fictional.

The creators and contributors of this project are not liable for any data loss or security breaches resulting from the use of this demo application. It is intended for educational and portfolio purposes only.
